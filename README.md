# 悦享外卖商家管理后台

## 项目介绍
一款面向中小外卖商家的一站式运营管理后台，覆盖订单处理、菜品/套餐管理、数据统计、员工管理等核心场景，采用前后端分离架构开发，旨在解决外卖商家日常运营效率低、数据管理混乱的问题。

## 技术栈
### 后端
- 框架：ASP.NET Core WebAPI 8
- 数据库：MySQL
- 日志组件：Serilog
- 对象存储：MinIO（菜品/套餐等图片存储）
- ORM：EF Core

## 核心功能
### 1. 数据统计模块
- 展示今日营业额、有效订单数、订单完成率、平均客单价、新增用户等核心数据
- 处理数据异常（如订单完成率NaN），添加兜底逻辑保证界面友好

### 2. 订单管理模块
- 分类展示待接单、待派送、已完成、已取消、全部订单
- 支持订单状态基础流转

### 3. 菜品/套餐管理模块
- 菜品/套餐基础CRUD（增删改查）
- 基于MinIO实现菜品图片上传、存储、回显

### 4. 系统基础能力
- 后端：接口参数校验、跨域配置、Serilog日志记录（接口请求/异常日志）
- 前端：统一请求拦截/响应拦截、空数据提示、基础交互反馈
